# GlassLinkXP

Puts the live G1000 softkey labels on a Stream Deck, by reading them off the
X-Plane 12 screen and republishing them as datarefs.

**To install: double-click `install.cmd`.**

It copies GlassLinkXP into `%appdata%\GlassLinkXP`, sets up its Python
environment, adds a desktop shortcut, and offers to install the small X-Plane
plugin it publishes into. Open it from that shortcut afterwards: with nothing
configured yet, the window walks you through setup a step at a time.

Requires Windows and X-Plane 12.1.1 or newer.

> **This is experimental.** Expect rough edges.

Everything else -- what to wire a Stream Deck button to, troubleshooting, the
settings reference, and what has and has not been tested against real
hardware -- is on the project page:

**https://github.com/rstalets/g1000-softkey**

(Kept short on purpose: this copy ships inside the zip, and documentation that
is maintained in two places is documentation that disagrees with itself. The
project page is the one that is kept current.)
